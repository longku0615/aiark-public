# AIArk

AIArk is a decentralized storage and value-search network with a creator marketplace, run on its own chain, AIArkChain. The native token **AIArk** is used for payments, staking, mining rewards and governance.

**Testnet stage: the token has no value and is not for sale; parameters may change. Nothing here is investment advice; digital assets are high-risk.**
